# Онлайн-запись для автосервисов и детейлинг-студий (Беларусь)

PWA: клиент записывается по ссылке без регистрации, владелец ведёт записи, оплаты и настройки в кабинете.
Одна сборка обслуживает много студий: новая студия — это папка `tenants/<slug>/` с `business.json` и фото.

- Клиент: `/s/<slug>/` — услуги и цены в BYN, фото работ, запись в нижней шторке (услуга → дата → время → данные),
  «Моя запись» с отменой, напоминание за сутки (событие календаря .ics).
- Владелец: `/s/<slug>/owner/` — записи на день и неделю, ручная запись, перенос, статусы, оплаты и возвраты,
  блокировки постов, итоги (заезды, выполненные, полученные деньги), настройки студии, услуги, посты, график, фото.
- Демо: `graphite` (детейлинг, Минск) и `protector` (шиномонтаж, Брест).
- Хостинг: Vercel (`vercel.json`, `pnpm build:vercel`); Cloudflare Pages — запасной, со старыми ссылками `*.pages.dev`.
