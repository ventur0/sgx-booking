# Автосервис SGX — запись в студию (без ИИ)

Приложение для записи в автосервис или детейлинг-студию. Работает по обычной ссылке
на телефоне и компьютере, клиенту не нужна регистрация. Ссылку можно добавить на главный
экран: откроется без адресной строки, со своей иконкой.

Помощника на ИИ в этой версии нет. Платные API не нужны: Supabase и Vercel работают
на бесплатных тарифах.

## Что умеет

**Клиент**: смотрит услуги, цены и работы; выбирает услугу → дату → свободное время →
вводит имя, телефон и машину → подтверждает. Занятое время зачёркнуто. В «Моей записи» видит
детали и может отменить запись по правилам студии. После записи можно включить напоминание
за сутки, а где уведомления недоступны, добавить запись в календарь.

**Владелец** (`/s/<студия>/admin`, вход по почте и паролю): видит записи на день и неделю,
количество заездов, завершённых работ и реально полученные деньги. Добавляет запись вручную,
переносит, отменяет, отмечает машину принятой или готовой, вносит оплату или возврат.
Меняет услуги, цены, длительность, боксы, часы, выходные, адрес, телефон, логотип,
главное фото, три карточки на главной и фото работ.

**Расчёт свободного времени**: по графику, занятости каждого бокса, длительности услуги
и времени на подготовку между машинами. Услуга «на 2 дня» занимает бокс оба рабочих дня.

**Надёжность**:
- запись создаётся одной функцией в базе; пересечение по боксу запрещено ограничением базы,
  поэтому из двух одновременных записей на одно время проходит только одна;
- повторное нажатие «Подтвердить» отправляет тот же ключ и не создаёт копию;
- владелец видит только свою студию (RLS), права проверяет сервер;
- в браузер попадает только публичный ключ Supabase; ключ service role нужен только командам `tenant:*`;
- предел частоты: не больше 5 записей с одного номера в сутки и 20 записей в минуту на студию.

## Установка (один раз)

Нужны Node.js 20+, pnpm, аккаунты Supabase и Vercel.

```bash
pnpm install
cp .env.example .env              # впишите ключи Supabase
pnpm exec supabase login
pnpm exec supabase link --project-ref <id проекта>
pnpm db:push                      # создаст таблицы, правила доступа и функции
pnpm exec playwright install chromium
pnpm test                         # проверка логики расчёта времени
```

В Vercel добавьте только `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` и при желании
`VITE_VAPID_PUBLIC_KEY`. Ключ service role в Vercel не добавляйте.

## Новая студия за несколько минут

Все данные студии лежат в одном файле `tenants/<адрес>/tenant.json`, фото — в `tenants/<адрес>/photos/`.
Код менять не нужно.

```bash
pnpm tenant:new glossy-kzn --name "Глосси" --owner owner@mail.ru --phone "+7 917 123-45-67" --address "Казань, ул. ..."
# заполните tenants/glossy-kzn/tenant.json: услуги, цены, часы, боксы, карточки
# положите фото в tenants/glossy-kzn/photos/ (hero.jpg, logo.png, work-1.jpg …) и поправьте пути в файле
pnpm tenant:check glossy-kzn      # проверка настроек и фото
pnpm deploy                       # сборка и публикация на Vercel
pnpm tenant:publish glossy-kzn    # занесёт студию в базу как ОБРАЗЕЦ и создаст вход владельцу
pnpm tenant:smoke glossy-kzn      # проверит готовую ссылку на телефоне и компьютере
pnpm tenant:publish glossy-kzn --approve   # уберёт метку «Образец»
```

Ссылка для клиентов: `https://<домен>/s/glossy-kzn/`, кабинет: `https://<домен>/s/glossy-kzn/admin`.
Команда `tenant:publish` печатает временный пароль владельца.

После публикации владелец меняет данные в кабинете, и они хранятся в базе.
Повторный `tenant:publish` их не перезаписывает (только с флагом `--overwrite-config`).

Иконка на телефоне берётся из логотипа. Для iPhone положите в папку студии `icon-192.png` и `icon-512.png`.

## Напоминания за сутки (по желанию)

1. `npx web-push generate-vapid-keys`; публичный ключ запишите в `VITE_VAPID_PUBLIC_KEY`.
2. `pnpm exec supabase secrets set VAPID_PUBLIC_KEY=… VAPID_PRIVATE_KEY=… VAPID_SUBJECT=mailto:you@mail.ru PUBLIC_SITE_URL=https://… CRON_SECRET=<случайная строка>`
3. `pnpm functions:deploy`
4. В SQL-редакторе Supabase включите pg_cron и pg_net и запустите:
   ```sql
   select cron.schedule('send-reminders', '*/15 * * * *', $$
     select net.http_post('https://<id>.supabase.co/functions/v1/send-reminders',
       headers => jsonb_build_object('Authorization', 'Bearer <CRON_SECRET>'));
   $$);
   ```
Без этих шагов кнопка уведомлений скрыта, а клиенту предлагается календарь (.ics с напоминанием за 24 часа).

## Структура

```
tenants/<slug>/tenant.json   настройки студии (схема: src/shared/tenantSchema.ts)
src/shared/slots.ts          расчёт свободного времени (тот же, что в базе)
supabase/migrations/         таблицы, RLS, функции записи, оплаты, отмены
supabase/functions/          отправка напоминаний
scripts/                     команды tenant:new / check / publish / smoke, сборка манифестов
src/pages, src/components    сайт для клиентов
src/admin                    кабинет владельца
src/sw.ts                    service worker: установка и работа без сети
```

## Что отличается от исходного ТЗ

- **Нет ИИ-помощника и OpenAI SDK**: убраны по вашей просьбе.
- **Astryx Design System и liquid-gl не подключены.** Оба пакета были недоступны при сборке
  проекта, и их API нельзя было изучить. Интерфейс собран на своих стилях (`src/styles.css`),
  стекло сделано через `backdrop-filter`. Чтобы подключить liquid-gl, замените класс `glass`
  на его компонент в двух местах: `TenantLayout.tsx` (нижняя панель) и `HomePage.tsx` (кнопка на фото).
- **Skill ui-ux-pro-max** в среде сборки недоступен.
